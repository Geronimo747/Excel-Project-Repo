# My-Excel-Project-Repo
This workbook is a Week 1 Excel training project for a Data Technician course, focused on developing practical Excel data analysis skills using datasets, Pivot Tables, formulas, and visualisations.

Project Overview

The workbook contains three main tasks:

1. Pivot Table Analysis

I used a bike sales dataset to:

-Create and explore Pivot Tables.
-Analyse sales by country, age group, and gender.
-Identify trends and business insights from the data.
-Reflect on findings and answer analysis questions.

Examples of findings recorded in the workbook include:

-Germany only has customers in the Adult age group.
-Australia and the UK have sales across all markets.
-The USA is highly profitable, particularly among adult customers.
-The USA youth market appears comparatively weak.
2. Pivot Tables and SWITCH Function

Using a product sales dataset from English counties, learners must:

-Create a Pivot Table showing sales volume by county and product.
-Apply the SWITCH function to categorise sales volumes as:
-High (>600)
-Medium (300-600)
-Low (<300)
-Demonstrate understanding of data summarisation and logical formulas.
3. Data Visualisation

Learners use a second bike sales dataset to:

-Create charts and visualisations.
-Explore sales trends visually.
-Gain experience presenting data in a clear and meaningful way.
-Skills Developed

The project builds skills in:

-Excel fundamentals
-Pivot Tables
-Data analysis
-Business insight generation
-Excel formulas and functions (especially SWITCH)
-Data visualisation and chart creation
-Working with real datasets
-Deliverables

By the end of the workbook, learners submit:

-Screenshots of completed Pivot Tables.
-Completed sales categorisation using SWITCH formulas.
-Screenshots of charts and visualisations.
-Answers to reflection and analysis questions.
-The completed workbook through Microsoft Teams.
